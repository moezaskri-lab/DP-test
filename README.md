# Référentiel DP Gexpertise

## Objectif

Ce référentiel définit les règles d'analyse utilisées pour contrôler
la complétude d'un dossier de Déclaration Préalable.

## Informations obligatoires

### Identification

- Commune
- Adresse
- Référence cadastrale
- Pétitionnaire

### Projet

- Nature des travaux
- Description de l'existant
- Description des travaux

## Critère de validation interne

Un dossier est considéré comme exploitable lorsque son
taux de complétude est supérieur ou égal à 85 %.
